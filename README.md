Docker.sh

Простой скрипт для установки Docker
Подходит для ряда OS (Debian,Ubuntu,Astra, тестировал только на Desktop системах!!! И только лишь для тестов!!!)
Docker-compose из apt устарел — сейчас актуален плагин docker compose (v2)
При запуске скрипта - выдает сообщение об установленной системе, а именно с которой запускается данный скрипт
su - ${USER} — внутри скрипта это бесполезно (запустится подпроцесс и сразу завершится), группу нужно применить заново после релогина
На старых версиях (Ubuntu 18.04) — не сработает!!! Подходите рационально!
